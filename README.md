# staircase_pancakes

Скиллозависимый 2D-рогалик на pygame-ce + pymunk.

Игрок висит на питонах, раскачивается, прыгает, кидает предметы. Управление - две руки (ЛКМ/ПКМ), тело, Q/E на предметы в руках. Есть стамина, гравитация, процедурные предметы из коробок. Имеет звуковой движок.

## Установка

```
pip install -r requirements.txt
```

## Запуск

```
python main.py
python main.py --map levels/test2.json
python main.py --cheats
python main.py --spawninfo
```

## Управление

- `A` / `D` - движение
- `Space` - прыжок
- `ЛКМ` / `ПКМ` - левая/правая рука (хват за питон или предмет)
- `Q` / `E` - использовать/бросить предмет из левой/правой руки
- `F` (зажать) - режим «только предметы»
- `Esc` - выход

## Уровни

JSON-файлы в `levels/`.

# Редактор уровней

### Запуск

```
python -m editor
```

### Что умеет

Инструменты на нижней панели: пеги, платформы, фоны, предметы, спавнеры. Выделение и перетаскивание - Shift + ЛКМ. Слои, блокировка, отмена, snap, зум и панорамирование (ПКМ / СКМ + колесо).

Фоны можно превращать в полигоны (ПКМ → Convert to polygon) и вращать - тяни за оранжевые дуги у углов.

Предметы cube и soda поддерживают `contents` - рекурсивный список взвешенных записей. Открывается через инспектор (правая панель), вложенный - через шестерёнку в записи.

Спавнеры задают точку и список взвешенных предметов - при загрузке уровня один из них выпадает в мир.

### Горячие клавиши

- `1..7` - инструменты (ghost, eraser, peg, platform, background, item, spawner)
- `Shift` + ЛКМ - выделение/перемещение
- `Ctrl+Z / Ctrl+Shift+Z` - undo/redo
- `Ctrl+S / Ctrl+O` - save/load
- `Delete` - удалить выделенное
- `Space` - центрировать на ghost
- `Esc` - выйти
