# Level scripts

Скрипты уровня — Python-файлы, привязанные к триггерам. Один файл на триггер, задаётся полем `script` в JSON триггера. Уровень может быть обычным `.json` или `.tar` (тогда `scripts/` внутри архива).

## События

Игра ищет в модуле функции с этими именами. Отсутствующие — игнорируются.

### Уровень

- `on_load(ctx)` — уровень загружен, все объекты уже созданы. Один раз.
- `on_unload(ctx)` — уровень выгружается. Один раз.

### Триггер

- `on_enter(ctx)` — игрок пересёк границу триггера снаружи внутрь.
- `on_exit(ctx)` — игрок вышел наружу.
- `on_tick(ctx)` — вызывается 20 раз в секунду, пока игрок внутри.

### Кнопки (пока игрок внутри триггера)

- `on_button_grab(ctx, tag)` — рука коснулась кнопки.
- `on_button_release(ctx, tag)` — рука отпустила кнопку (в том числе если отцепилась по расстоянию).
- `on_button_down(ctx, tag)` — игрок зажал Q/E, держа кнопку.
- `on_button_up(ctx, tag)` — игрок отпустил Q/E.

`tag` — это `id` кнопки из JSON, или `None` если `id` не задан.

## Состояние

Живёт в глобальных переменных модуля, сохраняется между вызовами пока уровень загружен.

```python
counter = 0

def on_enter(ctx):
  global counter
  counter += 1
  ctx.log(f"entered {counter} times")
```

## ctx

Объект, передаваемый в каждое событие. Единственный способ взаимодействия с миром.

### `ctx.log(msg)`

Печатает строку в консоль с префиксом `[scripts/foo.py]`.

### `ctx.by_id(id)`

Возвращает объект по `id` из JSON уровня, или `None`, если не найден. Работает для пегов, платформ, фонов, предметов, кнопок, триггеров.

```python
door = ctx.by_id("door_1")
if door is None:
  ctx.log("door not found")
```

### `ctx.move_to(target, x=None, y=None, dur=0.5, ease="out")`

Плавно перемещает объект. `target` — id или сам объект. `x` и `y` опциональны (можно двигать по одной оси).

Ease: `"linear"`, `"in"`, `"out"`, `"inout"`.

Повторный вызов на том же объекте отменяет предыдущее движение.

```python
ctx.move_to("door_1", y=500, dur=0.6)
```

### `ctx.cancel_move(target)`

Останавливает активное движение объекта.

### `ctx.random`

`random.Random` с детерминированным сидом. У тебя и у друга в мультиплеере даёт одинаковый результат, если оба выполняют одинаковые вызовы в одной и той же последовательности.

```python
if ctx.random.random() < 0.3:
  ctx.log("unlucky")
```

Не трогает глобальный `random` игры, спавнеры и вложенные коробки не сдвигаются.

## Ошибки

Исключение в скрипте не роняет игру. Печатается в формате `path(line,col) Error: msg`, скрипт продолжает работать, конкретное событие пропускается.

## id в JSON

Любой объект может иметь опциональное поле `id` — уникальная строка. Дубликаты игнорируются с предупреждением, берётся первый. Объекты без `id` не доступны через `ctx.by_id`.
