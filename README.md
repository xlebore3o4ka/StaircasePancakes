# staircase_pancakes

2D скиллозависимый рогалик на pygame-ce + pymunk. Игрок поднимается вверх по вертикальной башне, используя две руки. Монстров нет — вся сложность в механике движения. (Единственный монстр это твой друг в multiиграть)

## Основной цикл

Игрок висит на двух руках, раскачивается, прыгает, хватается за опоры. Камера следует за телом. Внизу — смерть (пока не реализовано как механика, но пол есть). Наверху — новые уровни (в планах).

## Управление

- **A / D** — ходьба по земле и платформам.
- **Space** — прыжок. С земли и с питона. Удержание не работает как серия — нужен переjump.
- **ЛКМ / ПКМ** — левая/правая рука. Тянется к курсору.
- **Q / E** — использовать/бросить предмет из соответствующей руки. С зажатием — усиленный удар (charge + пульс белым).
- **1 / 3** — карманы. Положить/достать предмет в слот (только с сумкой или с читами).
- **2** — свести руки вместе, при отпускании — поменять предметы в руках.
- **F** (удерживать) — режим «только предметы», питоны игнорируются.
- **Esc** — выход.

## Руки

Две независимые руки. Каждая цепляется за **питон** (статичная точка) или **кнопку** (объект взаимодействия). Когда рука держится за питон — между телом и питоном натягивается верёвка (SlideJoint), по которой можно подтягиваться. Тело раскачивается маятником, накапливает инерцию. Отпустил — летит.

Если рука держится за питон и стамина кончилась — рука автоматически разжимается.

Кнопки — особый тип: рука к ним притягивается, но тело остаётся под гравитацией. Это не верёвка, а «удержание». Q/E на граббе кнопки — нажатие.

## Стамина

У каждой руки своя. Тратится при удержании питона, при прыжке с питона. Восстанавливается при свободной руке. Если в кармане этой руки лежит предмет — тратится быстрее, восстанавливается медленнее.

Руки краснеют по мере падения стамины. При низкой стамине — тряска.

## HP

100 единиц максимума. Урон от падения: ниже 700 px/s — без урона, выше — пропорционально скорости. HP восстанавливается со временем, но блокируется на 5 сек после любого урона. Тело краснеет по мере потери HP. Стамина не может быть больше текущего HP.

На экране красное наложение при HP ниже 80, нарастает к 0.

## Предметы

Физические объекты, которые можно взять в руку, бросить, использовать.

- **Куб** — открывается при Q/E, выдаёт случайный предмет из своего содержимого (по умолчанию — сода 2/3, ничего 1/3). Содержимое настраивается в JSON, может быть вложенным (куб в кубе).
- **Сода** — восстанавливает стамину, летит в игрока с анимацией.
- **Арматура** — длинная палка. Q/E стреляет ею по направлению, отдача толкает тело. Втыкается в стену, после чего становится граппла-точкой как питон.
- **Ручной питон** — при использовании (над фоном) превращается в статический питон. Если под ним нет фона — вылетает из руки.
- **Сумка** — при использовании открывает карманы и наполняет их содой и пустым кубом.

Предметы отображаются в HUD рядом с соответствующими руками. Держимый предмет рисуется полупрозрачно под рукой.

## Мир

Уровень загружается из JSON или tar-архива. Платформы — статические препятствия (прямоугольники или полигоны). Фоны — декоративные прямоугольники/полигоны. Питоны — точки хвата. Кнопки — интерактивные зоны. Триггеры — невидимые зоны со скриптами.

Каждый объект может иметь `id` для обращения из скриптов. Слои (`layer`) задают порядок отрисовки.

Спавнеры предметов при загрузке один раз бросают по весам — что выпадет в точке.

Сид (`seed`) в JSON детерминирует рандом. Отсутствует — каждый запуск свой.

## Скрипты уровней

Python-файлы, привязанные к триггерам. События: загрузка/выгрузка уровня, вход/выход/тик в зоне, захват/нажатие кнопок. API через `ctx`: `log`, `by_id`, `move_to`, `cancel_move`, `random`, `shake`. Скрипты могут перемещать объекты плавно (используя kinematic velocity для корректного взаимодействия с физикой).

## Мультиплеер

WebSocket relay. Сервер раздаёт карту при подключении, клиенты видят друг друга как полупрозрачных призраков с ником. Свой мир у каждого — физика и предметы локальные, синхронизируются только визуальные позиции, состояния и звуки. Воткнутые арматуры и ручные питоны синхронизируются как события. Читы (`--cheats`) включают бесконечную стамину, полёт по пробелу, открытые карманы.

## Звук

`SoundManager` грузит файлы формата `name-N.wav` из `sounds/`, играет случайный из вариантов. События звука транслируются другим игрокам с половиной громкости, если эмиттер в кадре.

## Отладка

- **`--debugview`** — метки спавнеров, зоны триггеров, стрелки с `id` ко всем объектам.
- **`--debuginfo`** — позиция, скорость, HP, стамина в правом верхнем углу.
- **`--cheats`** — для тестов.
- **`--map`** — путь к уровню.
- **`--name`, `--server`** — мультиплеер.

## Структура

- `game/` — игра.
- `game/core/` — окно, физика, камера.
- `game/entities/` — игрок, предметы, объекты мира.
- `game/net/` — сетевой клиент, синхронизация.
- `game/scripts/` — API для скриптов уровней.
- `net/` — сервер и утилиты.
- `shared/` — константы, версия, хеши, общие утилиты.
- `levels/` — json и tar-уровни.
- `sounds/` — звуковые файлы.
- `editor/` — редактор уровней (отдельный проект).
- `launcher.py` — графический лаунчер (single / multi / выбор карты).

## Версия

`VERSION` в корне. `major.minor.patch`. В мультиплеере соединяются только `major.minor`.
