# staircase_pancakes

Скиллозависимый 2D-рогалик на pygame-ce + pymunk.

Игрок висит на питонах, раскачивается, прыгает, кидает предметы. Управление — две руки (ЛКМ/ПКМ), тело, Q/E на предметы в руках. Есть стамина, гравитация, процедурные предметы из коробок.

## Установка

```
pip install -r requirements.txt
```

## Запуск

```
python main.py
python main.py --map levels/test2.json
python main.py --cheats
python main.py --spawninfo
```

## Управление

- `A` / `D` — движение
- `Space` — прыжок
- `ЛКМ` / `ПКМ` — левая/правая рука (хват за питон или предмет)
- `Q` / `E` — использовать/бросить предмет из левой/правой руки
- `F` (зажать) — режим «только предметы»
- `Esc` — выход

## Уровни

JSON-файлы в `levels/`. Формат: `pegs`, `platforms`, `backgrounds`, `items`, `itemSpawners`, опциональный `seed`.

Редактор уровней — отдельный проект `editor/`.

## Структура

- `game/` — игра
- `shared/` — общие константы и утилиты
- `editor/` — редактор уровней
- `sounds/` — звуки в формате `name-N.wav` (N — номер варианта)
- `levels/` — JSON-уровни
